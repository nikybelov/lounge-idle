# Lounge Idle

Браузерный idle/кликер: карьера от помощника кальянного мастера до своего лаунжа.

## Как играть

1. **Смена** в выбранном заведении — задачи (миска, угли, заказ), копишь выручку.
2. **Свой лаунж** — вкладка открывается от 9k; тарифы Первая тяга / Сладкий пар / Дымный мир.
3. Если касса пустеет — можно снова **на смену**.
4. Когда свой доход стабилен — **уволиться** и развивать только свой лаунж.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/`.

Прогресс хранится в `localStorage` браузера.

## Публичная ссылка (GitHub Pages)

**Играть:** https://nikybelov.github.io/lounge-idle/

Каждый пуш в `main` собирает игру и обновляет сайт автоматически (Actions → **Deploy to GitHub Pages**).

Админ для тестов: добавь `?admin=1` к URL. Выключить: `?admin=0`. Новая карьера: `?reset=1`.

## Стек

Vite + TypeScript + DOM. Без React.
